# Hangman Flutter 

## Funcionalidades
* Adivinhação de palavras.
* Interface de Usuário simples e intuitiva.
* Suporte multiplataforma (Android, iOS, Web).

## Primeiros Passos
Para obter uma cópia local funcionando, siga estes passos.

### Pré-requisitos
Certifique-se de ter o Flutter SDK instalado em sua máquina. Se ainda não o configurou, confira o [guia oficial de instalação do Flutter](https://docs.flutter.dev/get-started/install).

### Instalação

1. Clone o repositório:
   ```
   git clone <url-do-seu-repositorio>
   ```

2. Navegue até o diretório do projeto:
   ```
   cd hangman_flutter
   ```

3. Instale as dependências necessárias:
   ```
   flutter pub get
   ```

4. Execute o aplicativo:
   ```
   flutter run
   ```
